## Asset Processing Walkthrough

### Logo Conversion Process

**Source**: `Branding/logo full color.pdf`

**Step 1**: Extract Logo
- Open PDF in design software
- Export as PNG (300×300px, transparent background)
- Export as SVG (scalable vector)

**Step 2**: Create Variants
- 300×300px → logo.png
- 150×150px → logo-150.png
- 100×100px → logo-100.png
- 300×300px → logo.svg

**Step 3**: Create Favicon
- 64×64px base → favicon.ico (multi-size)
- 64×64px → favicon-32.png
- 64×64px → favicon-16.png
- 180×180px (with border) → apple-touch-icon.png

**Output Files**:
- Branding/logo.png
- Branding/logo-150.png
- Branding/logo-100.png
- Branding/logo.svg
- Root/favicon.ico
- Root/favicon-32.png
- Root/favicon-16.png
- Root/apple-touch-icon.png
