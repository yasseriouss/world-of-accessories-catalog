# 🌐 Modern Web Catalog & Admin Dashboard (موقع الكتالوج ولوحة التحكم)

تطبيق ويب متكامل مصمم خصيصاً للعملاء لتصفح المنتجات بتجربة تفاعلية سلسة ومتحركة، مع لوحة تحكم خاصة لإدارة المنتجات والصور وتوليد الكتالوجات المطبوعة.

---

## 🌟 مميزات موقع العميل (`/`):
- **تصميم فائق الدقة ومتجاوب:** يعمل بسلاسة على الجوال، التابلت، والشاشات الكبيرة.
- **تفاعل وتحركات حية (Animations):** ظهور تدريجي للمنتجات، بطاقات تفاعلية مع تأثيرات حركية عند التحويم.
- **بحث فوري مع فلترة لحظية:** بالاسم (عربي وإنجليزي)، الكود، أو الفئة.
- **أزرار الفئات التفاعلية (Category Pills):** استعراض المنتجات حسب الفئات العشر مع عرض أعداد المنتجات.
- **نافذة المعاينة السريعة (Quick View Modal):** فحص كامل لمواصفات المنتج وصورته، ونسخ كود المنتج بنقرة واحدة.
- **طلب فوري عبر واتساب:** زر مخصص لكل منتج يفتح محادثة واتساب مجهزة مسبقاً بكود واسم وسعر المنتج.
- **ثنائي اللغة (Bilingual):** تبديل سلس ولحظي بين العربية (RTL) والإنجليزية (LTR).

---

## 🔒 لوحة التحكم الإدارية (`/admin`):
- **حماية خاصة بالرمز السري (PIN Protected):** رمز المرور الافتراضي: `2026`.
- **إدارة كاملة للمنتجات (Full CRUD):**
  - إضافة منتج جديد (اسم عربي، اسم إنجليزي، فئة، سعر).
  - تعديل فوري لأسعار ومواصفات أي منتج مسجل.
  - حذف المنتجات مع تأكيد آمن.
- **إدارة ورفع الصور:** إمكانية رفع صور جديدة للمنتجات مباشرة وحفظها تلقائياً.
- **تكامل وتوليد تلقائي (Auto-generation):** عند إضافة أو تعديل أي منتج، يتم إطلاق محرك توليد الكتالوجات المطبوعة في الخلفية تلقائياً.
- **زر توليد يدوي مباشر (On-Demand):** لتوليد كافة الكتالوجات والكتيبات المطبوعة في ثوانٍ معدودة مع شريط تقدم.
