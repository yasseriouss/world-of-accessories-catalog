# 🛒 World of Accessories - E-Commerce Website

Public-facing e-commerce and product catalog website.

## Features

- 🌍 Bilingual support (Arabic/English)
- 📱 Fully responsive design
- 🛍️ Product marketplace with categories
- 🛒 Shopping cart functionality
- 📖 Digital and printed catalogs
- 📊 Advanced search and filtering
- 💳 WhatsApp ordering integration
- 🎨 Luxury brand styling
- ♿ Accessibility features
- 🔐 Security headers configured

## Pages

- `/` - Landing page
- `/market` - Product marketplace
- `/catalog` - Category browsing
- `/about` - Company information
- `/print` - Printed catalog center

## Deployment

This app is deployed independently to Vercel.

```bash
# Local development
cd apps/ecommerce

# Deploy
vercel deploy
```

## Environment

- **Production URL**: `https://accessories-world.vercel.app`
- **Preview**: Auto-deployed on pull requests

See `vercel.json` for deployment routing and headers.
