# خطة تنفيذ SEO لموقع World of Accessories
## (خطة عمل لتحويل المحتوى الجاهز إلى موقع متصدّر)

---

## المرحلة 1: التأسيس التقني (الأسبوع 1) — مالك: مطوّر الموقع

| # | المهمة | التفاصيل | الحالة |
|---|---|---|---|
| 1.1 | رفع الصور بأسماء SEO | استخدم مجلد `seo-images/` الجاهز (588 صورة بأسماء وصفية) + ألصق `alt_text_ar` من report.csv لكل صورة عند الرفع | ✅ جاهز |
| 1.2 | حقن Structured Data | الصق محتوى `product-schema.jsonld` في `<head>` (أو عبر إضافة Schema) — بعد استبدال example.com بالدومين الحقيقي | ✅ جاهز |
| 1.3 | sitemap + robots | ارفع `sitemap.xml` و`robots.txt` لجذر الموقع (عدّل الدومين أولًا) ثم أرسل Sitemap في Search Console | ✅ جاهز |
| 1.4 | حقول المنتجات | لكل منتج: Title=`seo_title_ar`، Meta=`meta_desc_ar`، الرابط=`slug`، الوصف=`seo_desc_ar` (استورد report.csv كمرجع) | ✅ جاهز |
| 1.5 | السرعة (Core Web Vitals) | حوّل الصور إلى WebP، فعّل lazy-load وCDN (Cloudflare) وكاش — الهدف LCP < 2.5 ثانية | يدوي |
| 1.6 | نسخة موبايل + HTTPS | فعّل شهادة SSL وتأكد من تجاوب القالب (70% زيارات مصر موبايل) | يدوي |

## المرحلة 2: صفحات الفئات والمحتوى (الأسبوع 2) — مالك: محتوى/تسويق

| # | المهمة | التفاصيل | الحالة |
|---|---|---|---|
| 2.1 | أنشئ 10 صفحات فئات | الرفع من `categories-content.md` (عنوان + meta + 350 كلمة + FAQ لكل فئة) بروابط `/category/{slug}` المطابقة للـ sitemap | ✅ جاهز |
| 2.2 | FAQ Schema | أضف FAQPage JSON-LD لكل فئة من أسئلة الملف نفسه | ✅ نص جاهز |
| 2.3 | أدلة شراء | مقالان شهريًا: "أفضل مجرى درج سوفت كلوز 2026"، "دليل اختيار المطبقية" — يستهدفان كلمات معلوماتية | مقترح |
| 2.4 | Canonicals | للمنتجات المتشابهة (مقاسات) ضع canonical لأقوى نسخة إذا لم تكن كل صفحة فريدة بما يكفي | يدوي |

## ⚠️ قواعد لا تكسرها
- لا تشتري روابط جماعية ولا تكرر الكلمات بشكل اصطناعي (الحزمة الحالية فريدة 100%)
- لا تضف أسعارًا أو تقييمات وهمية في Schema
- أي منتج جديد يدخل بنفس القالب: صورة + slug + title + meta + schema
