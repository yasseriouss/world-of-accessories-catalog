## 🌟 1. المشروع الأول: موقع كتالوج الويب ولوحة التحكم (`web_catalog/`)

### واجهة العميل (Customer Experience):
- **رابط التصفح:** `http://localhost:8080/`
- **متجاوب 100%:** يعمل بسلاسة على الهاتف المحمول، الأجهزة اللوحية، وشاشات الحواسيب.
- **تفاعل وتحركات حية (Animations):** ظهور تدريجي، بطاقات تفاعلية مع تأثيرات حركية أنيقة.
- **بحث فوري مع فلترة لحظية:** بالاسم، الكود، أو الفئة.
- **معاينة سريعة (Quick View Modal):** لمشاهدة تفاصيل المنتج وتكبير الصورة ونسخ الكود بنقرة واحدة.
- **طلب مباشر عبر واتساب:** يرسل محادثة مجهزة مسبقاً بكود واسم وسعر المنتج.
- **ثنائي اللغة:** تبديل لحظي بين العربية (RTL) والإنجليزية (LTR).

### لوحة التحكم الإدارية الخاصة (Admin Dashboard):
- **رابط اللوحة:** `http://localhost:8080/admin`
- **الحماية:** محمية برمز مرور سري (PIN الافتراضي: `2026`).
- **إضافة وتعديل المنتجات (CRUD):** إضافة منتجات جديدة، تعديل الأسعار، وتغيير الفئات.
- **رفع الصور:** إمكانية رفع صور جديدة للمنتجات مباشرة مع معاينة فورية.
- **المزامنة والتوليد التلقائي:** يتم إطلاق محرك توليد الكتالوجات في الخلفية تلقائياً عند حفظ أي تعديل.
- **زر توليد يدوي (On-Demand):** لتحديث وإعادة إنشاء كافة ملفات الكتالوجات في ربع ثانية.

## 📖 2. المشروع الثاني: محرك توليد الكتالوجات (`catalog_generator/`)

- محرك بايثون مستقل وسريع للغاية (يولد أكثر من 65 صفحة A4 و22 ملف كتيب في أقل من 0.25 ثانية).
- يقرأ مباشرة من المصدر المركزي `data/products.json`.
- يولد:
  1. `catalog_ar.html`: الكتالوج العربي الشامل الفاخر (أرقام مشرقية، حماية BiDi، غلاف، فهرس صفحات).
  2. `catalog_en.html`: الكتالوج الدولي الشامل بالإنجليزية.
  3. `Categories/category_01` إلى `category_10`: كتيبات الفئات العشر المستقلة.
- يمكن تشغيله مباشرة عبر سطر الأوامر:
  ```bash
  python catalog_generator/cli.py
  ```

## 🚀 تشغيل النظام الشامل (Run Project)

لتشغيل السيرفر الموحد:
```bash
python run.py
```
- موقع العميل: `http://localhost:8080/`
- لوحة التحكم: `http://localhost:8080/admin` (رمز الدخول: `2026`)
