<h2>ماذا تحتاج قبل البدء؟</h2>
<ul>
<li>مسطرة معدنية ومازورة (متر).</li>
<li>مثقاب بريمة 3 و5 ملم.</li>
<li>مفك نجارة + مطرقة خفيفة.</li>
<li>المسامير المرفقة مع السكة (لا تستبدلها بأطول!).</li>
</ul>
<h2>الخطوة 1: قياس العمق</h2>
<p>قس عمق الخزانة الداخلي من الخلف للواجهة. اختر سكة بنفس العمق تقريباً: خزانة 45 سم ← سكة 45 سم.</p>
<h2>الخطوة 2: تحديد ارتفاع السكة</h2>
<p>ارفع السكة عن قاع الخزانة بمقدار الارتفاع المكتوب على قاعدة التاندم (عادة 12–15 ملم حسب السماكة). استخدم الـ Template المرفق — ثبته بالمسمارين الخلفيين.</p>
<h2>الخطوة 3: تركيب الأدراج</h2>
<p>أدخل السكة حتى تسمع «طقطقة» القفل الخلفي، ثم أغلق القفل الأمامي بأداة الضبط المرفقة.</p>
<h2>الخطوة 4: ضبط الواجهة (3D)</h2>
<ul>
<li><strong>الارتفاع:</strong> عجلة الضبط الأمامية ترفع الدرج ±2 ملم.</li>
<li><strong>الجانب:</strong> المسمار الجانبي يحرك الواجهة يميناً ويساراً.</li>
<li><strong>العمق:</strong> مسمار الضبط الخلفي يقرّب الواجهة أو يبعدها.</li>
</ul>
<h2>الأخطاء التي تدمر التركيب</h2>
<ul>
<li>عدم تسوية السكتين على نفس الارتفاع ← الدرج يميل.</li>
<li>تثبيت بمسمار واحد فقط ← اهتزاز وصوت.</li>
<li>تجاهل فكرة الأدراج المنظمة: ركب القفل الأمامي قبل تعديل الواجهات.</li>
</ul>
